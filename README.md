# AI-Based Air Quality Prediction System

An AI-powered web application that predicts Air Quality Index (AQI) using Machine Learning and provides real-time air quality monitoring.

## Features

- User registration and login system
- AQI prediction using Machine Learning
- Real-time AQI monitoring
- City-wise air quality analysis
- Weather information integration
- Prediction history tracking
- Dashboard with AQI statistics
- Data visualization
- Export prediction history

## Technologies Used

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- Random Forest Regressor
- Pandas
- NumPy

### Database
- SQLite

### Frontend
- HTML
- CSS
- JavaScript

### APIs
- OpenWeather API

## Machine Learning Model

Algorithm:
- Random Forest Regressor

Model Performance:
- R² Score: 0.94
- RMSE: 8.52
- MAE: 6.11
